## Présentation

**Notes** est une **collection de notes personnelles et professionnelles** centrée sur l’informatique, la cybersécurité et le pentest.  
Elle vise à **centraliser et organiser des ressources, des guides, des synthèses et des standards** dans un format structuré, consultable facilement via Markdown ou GitHub Pages.

---

## SuperDocs

Ce projet va de pair avec [SuperDocs](https://github.com/cos-imo/SuperDocs).
SuperDocs permet de découvrir et d’accéder rapidement à des documents, articles, tutoriels et RFC utiles pour l’informatique, la cybersécurité et le pentest.

## Installation

### Téléchargement

###### Par SSH
```bash
git clone git@github.com:cos-imo/Notes.git
````

###### Par HTTPS

```bash
git clone https://github.com/cos-imo/Notes.git
```

### Utilisation

Les notes sont en **Markdown**, aucun outil complexe n’est nécessaire : ouvrez les fichiers avec votre éditeur favori ou via GitHub Pages.

Pour utiliser mdbook en local :

```bash
mdbook serve
```

## Structure

Le dépôt est organisé comme suit:

- `Active\ Directory/` – Notes sur Active Directory
- `Network/` – Notes sur le réseau
- `Web/` – Notes sur le pentest de web apps
- `OS/` – Notes sur les systèmes d'exploitation
- `Forensics/` – Analyse post-incident, récupération de données, journaux, mémoire, stéganographie
- `DevOps/` –  CI/CD, conteneurs, cloud, automatisation sécurisée
- `Policies/` – RFCs, standards, guides de bonnes pratiques et compliance

Chaque sous-dossier contient des fichiers **Markdown** pour les documents, outils et ressources correspondantes.
